# Factory Floor Fear

"Create a 3D first-person horror game using React, Tailwind CSS, and Three.js. Build a dark, claustrophobic 3D environment resembling an abandoned toy factory office with creepy industrial decorations. Give the player a first-person perspective controller using the mouse to look around and WASD keys to walk. Give the player a flashlight toggle button (press F). In the center of the room, place a 3D desk with a 'Security Keycard' item glowing on top of it."
